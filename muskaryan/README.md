# Muskaryan 💕

A private couple's app built with React.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Install Tailwind CSS:
```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

3. Start the app:
```bash
npm start
```
